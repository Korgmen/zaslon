# Zaslon

Kill switch для приложений на macOS, живёт в меню-баре. Если публичный IP не в белом списке, выбранные процессы замораживаются (`SIGSTOP`). Когда разрешённый IP возвращается в течение `grace`, они размораживаются (`SIGCONT`). Иначе Zaslon закрывает их: сначала `SIGTERM`, затем `SIGKILL`. Пока IP плохой, новые запуски этих процессов сразу убиваются.

## Сборка и запуск

```sh
./build.sh
open build/Zaslon.app
```

Проверка без заморозки (ничего не трогает, конфиг не пишет):

```sh
./build/Zaslon.app/Contents/MacOS/Zaslon --check
```

При первом запуске текущий IP попадает в белый список, поэтому запускай с включённым VPN.

## Установка из DMG

```sh
./dmg.sh
```

Скрипт собирает `build/Zaslon-<версия>.dmg`. Открой образ и перетащи Zaslon в «Программы». Перед запуском установленной копии закрой ту, что запущена из `build/`. Две запущенные копии работают независимо друг от друга, и каждая замораживает приложения.

Автозапуск включается переключателем «Запускать при входе в систему» в настройках (раздел «Запуск») или одноимённым пунктом меню. Zaslon регистрируется в «Объектах входа» через `SMAppService` по тому пути, откуда запущен, поэтому включай автозапуск в копии из «Программ». Копия из `build/` зарегистрирует свой путь в `build/`.

Сборка подписана ad-hoc, без Developer ID. На своём Mac она запускается как обычно. На другом Mac скачанный образ заблокирует Gatekeeper. Тогда открой приложение правым кликом → «Открыть» или выполни `xattr -dr com.apple.quarantine /Applications/Zaslon.app`.

## Иконка

`AppIcon.icns` лежит в репозитории, `build.sh` копирует её в бандл. Иконку рисует `icon.swift` из векторов, каждый размер отдельно. Пересобрать после правки:

```sh
xcrun --sdk macosx swiftc -sdk "$(xcrun --show-sdk-path)" icon.swift -o build/make-icon && build/make-icon AppIcon.icns
```

## Как устроено

- IPv4 спрашивается у 5 сервисов параллельно, адрес принимается, когда `min_agree` из них ответили одинаково. IPv6 спрашивается у 3 сервисов, достаточно одного ответа.
- Страна определяется через `ipinfo.io`, при неудаче через `api.country.is`, с кэшем.
- Событие сети (`NWPathMonitor`): если сеть пропала или изменился набор интерфейсов (например, исчез туннель VPN `utun`), процессы замораживаются сразу и IP перепроверяется. Если IP прежний, через 1–2 с они размораживаются. На остальные события (DNS, роуминг Wi-Fi) IP перепроверяется без заморозки.
- Сон: время, пока Mac спал или Zaslon был остановлен, не входит в паузу до закрытия. После пробуждения отсчёт `grace` начинается заново.
- Во время заморозки проверка идёт каждые 2 с, в нормальном режиме раз в `check_interval`.
- DNS-резолвер (`whoami.akamai.net`) только показывается в меню и на решение не влияет.
- При выходе, `kill` или Ctrl+C всё размораживается. При старте Zaslon шлёт `SIGCONT` подходящим процессам на случай, если прошлый запуск упал.

## Лог

Лог пишется в `~/Library/Logs/Zaslon.log`. Открыть его можно из меню, пункт «Открыть лог» (⌘L), — он откроется в «Консоли». В лог попадают:

- старт и выход;
- события сети с интерфейсами;
- каждая пауза с причиной;
- каждое возобновление с длительностью;
- закрытие приложений;
- неудачные проверки с ответами сервисов;
- изменения настроек;
- сон и пробуждение.

Когда файл вырастает больше 1 МБ, он переименовывается в `Zaslon.log.1`.

## Настройки

Окно «Настройки…» в меню (⌘,):

- защищённые приложения: кнопка «Выбрать приложения…» открывает список установленных и запущенных программ с галочками и поиском; для CLI-инструментов есть поле «своё правило»;
- разрешённые IP, подсети и страны;
- таймеры, число согласных IP-сервисов и проверка IPv6.

Изменения применяются сразу. Если приложение убрать из защиты, пока оно заморожено, оно тут же размораживается.

Настройки хранятся в `~/Library/Application Support/Zaslon/config.json`. Файл можно править и руками: он перечитывается при сохранении.

| ключ | по умолчанию | смысл |
|---|---|---|
| `apps` | `["/Claude.app/"]` | подстроки командной строки процесса (`ps -o command`), без учёта регистра |
| `allow_ips` | текущий IP | адреса и подсети: `"185.12.40.0/24"`, `"2001:db8::/32"` |
| `allow_countries` | `[]` | коды стран: `["NL", "DE"]` |
| `grace` | `20` | сколько секунд держать заморозку до закрытия |
| `close_timeout` | `5` | сколько секунд между `SIGTERM` и `SIGKILL` |
| `check_interval` | `5` | сколько секунд между проверками в нормальном режиме |
| `min_agree` | `2` | сколько IPv4-сервисов должны назвать один адрес |
| `check_ipv6` | `true` | считать ли утечкой IPv6 не из белого списка |

## Ограничения

- Защита работает на уровне приложений, не сети: между сменой сети и заморозкой проходят миллисекунды.
- Процессы root и других пользователей не затрагиваются.
- Нет split-routing-проверки через сами ИИ-сервисы, Telegram, автозапуска (добавь в Login Items вручную) и подписи Developer ID (сборка подписана ad-hoc).
