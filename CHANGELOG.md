# Changelog

## 0.1 — 12.11.2026

Первая версия.

### Защита
- IPv4 проверяется по пяти сервисам с правилом согласия.
- Есть проверка IPv6 и показ DNS-резолвера в меню.
- Белый список задаётся адресами, подсетями и странами.
- Заморозка `SIGSTOP`, разморозка `SIGCONT`. Закрытие после паузы: `SIGTERM`, затем `SIGKILL`.
- Пока IP не разрешён, новые запуски защищённых приложений блокируются.
- На смену сети с изменением интерфейсов приложения замораживаются сразу. На прочие события сети IP только перепроверяется.
- Время сна Mac не входит в паузу до закрытия.
- Если ответили не все сервисы, но все назвали один адрес, адрес принимается.

### Интерфейс
- Меню в меню-баре: статус, IP, страна, быстрые действия.
- Окно настроек с пояснениями к параметрам «Поведения» и разделом «О приложении».
- Окно выбора защищаемых приложений с поиском.

### Сборка и диагностика
- Лог в `~/Library/Logs/Zaslon.log`.
- Режим `--check` для проверки без заморозки.
- Сборка `.app` скриптом `build.sh`, образ DMG скриптом `dmg.sh`.
