# Changelog

## 0.3 — 24.11.2026

### Добавлено
- Версия для Windows 10 и 11 (x64) в `windows/`: значок в области уведомлений, окно настроек, выбор приложений из меню «Пуск», автозапуск через планировщик задач, режим `--check`. Проверка IP по тем же правилам, что на macOS. При неразрешённом IP защищённые exe получают блокирующие правила брандмауэра Windows, их IPv4-соединения рвутся. Приложения не закрываются, сеть возвращается вместе с разрешённым IP.
- Релиз по тегу собирает и exe для Windows.
- `icon.swift` рисует и `windows/AppIcon.ico`.

## 0.2 — 12.11.2026

### Добавлено
- Компактный режим строки меню (`compact_menu_bar`): только цветная точка статуса, без IP, страны и обратного отсчёта. Включается в настройках, раздел «Строка меню».

## 0.1.1 — 12.11.2026

### Исправлено
- Ложные паузы на 2–7 с при кратковременных замираниях сети через VPN. Если на проверку не ответил ни один IP-сервис, Zaslon сразу проверяет ещё раз и ставит паузу, только если молчат две проверки подряд. Смена или пропажа сети по-прежнему ставит паузу мгновенно.

## 0.1 — 12.11.2026

Первая версия.

### Защита
- IPv4 проверяется по пяти сервисам с правилом согласия.
- Есть проверка IPv6 и показ DNS-резолвера в меню.
- Белый список задаётся адресами, подсетями и странами.
- Заморозка `SIGSTOP`, разморозка `SIGCONT`. Закрытие после паузы: `SIGTERM`, затем `SIGKILL`.
- Пока IP не разрешён, новые запуски защищённых приложений блокируются.
- На смену сети с изменением интерфейсов приложения замораживаются сразу. На прочие события сети IP только перепроверяется.
- Время сна Mac не входит в паузу до закрытия.
- Если ответили не все сервисы, но все назвали один адрес, адрес принимается.

### Интерфейс
- Меню в меню-баре: статус, IP, страна, быстрые действия.
- Окно настроек с пояснениями к параметрам «Поведения» и разделом «О приложении».
- Окно выбора защищаемых приложений с поиском.
- Иконка приложения: белый щит с оранжевой паузой. Генератор `icon.swift`.
- Автозапуск при входе в систему: переключатель в настройках и пункт меню.

### Сборка и диагностика
- Лог в `~/Library/Logs/Zaslon.log`.
- Режим `--check` для проверки без заморозки.
- Сборка `.app` скриптом `build.sh` (универсальный бинарник arm64 и x86_64), образ DMG скриптом `dmg.sh`.
- Релиз DMG через GitHub Actions по тегу версии.
